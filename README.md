# Léemelo 🎧

App web para escuchar en voz alta PDF, Word, EPUB, texto, fotos y pantallazos. Funciona en el navegador y se puede instalar en Windows, iPhone, iPad y Android.

- Los documentos se quedan en el dispositivo. Por defecto usa voces locales; las voces marcadas con 🌐 envían el texto a internet (Microsoft/Google).
- Usa librerías de código abierto cargadas desde CDN: pdf.js (Apache-2.0), mammoth (BSD-2), JSZip (MIT/GPLv3), Tesseract.js (Apache-2.0).
