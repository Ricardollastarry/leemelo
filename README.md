# Léemelo 🎧

App web para escuchar en voz alta PDF, Word, EPUB, texto, fotos y pantallazos. Funciona en el navegador y se puede instalar en Windows, iPhone, iPad y Android.

- Los documentos se quedan en el dispositivo. Por defecto usa voces locales; las voces marcadas con 🌐 envían el texto a internet (Microsoft/Google).
- Usa librerías de código abierto cargadas desde CDN: pdf.js (Apache-2.0), mammoth (BSD-2), JSZip (MIT/GPLv3), Tesseract.js (Apache-2.0), ONNX Runtime Web (MIT).

## Voz «Elena» (solo en ordenador)
Elena es la voz F1 del modelo **Supertonic 3** de Supertone Inc., licencia [BigScience OpenRAIL-M](https://huggingface.co/Supertone/supertonic-3/blob/main/LICENSE). El modelo (~385 MB) se descarga desde su página oficial de Hugging Face y se ejecuta en el propio dispositivo; no se incluye en este repositorio. Al usarla se aceptan sus restricciones de uso (Anexo A de la licencia): no suplantar a personas, no engañar ni hacer daño, y avisar de que el audio está generado por IA.
